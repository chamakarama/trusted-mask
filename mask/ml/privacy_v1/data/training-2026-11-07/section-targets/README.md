# Derived section supervision

Generated deterministically from the adjacent reviewed authored datasets using `section_audit`, with `clause-probe-v1`. Source hashes are in each export. These are projections of existing labels, not new or independently reviewed examples. Preserve IDs, families and splits. `target: null` is unlabelled and must not become a negative label. These files are intended for a future dedicated section head; the current `train.py` does not accept this format. Do not concatenate them into the canonical JSONL training set.

See ../../../SECTION_REMOVAL.md for the experiment, generation command and promotion criteria.
