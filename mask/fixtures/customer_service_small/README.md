# Development fixture: customer_service_small

120 train-split conversations (1433 turns, 120 customers) sampled with seed 7 from the
supplied synthetic TrustED package (CC BY 4.0, Since AI ry). `gold/` holds the public span labels for these
records so detection can be measured locally. Development only: metrics on this fixture are not benchmark results.
The organiser-held eval split is not included.
